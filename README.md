 OmniSense AI: Spatial Intelligence for the Visually ImpairedOmniSense AI is a wearable, vision-based assistive technology designed to solve the critical challenge of indoor navigation for the visually impaired. While traditional white canes are limited to detecting ground-level obstacles and lack landmark recognition, OmniSense provides complete 3D spatial awareness without relying on expensive, infrastructure-dependent beacon systems. Built for the Healthcare & Medicine category, this prototype transforms a standard smartphone camera and local processing unit into an intelligent copilot that actively maps rooms, detects hazards, and routes the user via conversational audio.   ⚙️ Core ArchitectureThe system runs on a lightweight, dual-model Python pipeline:Perception (YOLOv8): Real-time semantic object detection to identify landmarks (doors, chairs) and dynamic hazards.   Spatial Mapping (MiDaS): Monocular depth estimation that calculates the exact distance of identified objects and walls.   Audio Guidance (pyttsx3): A text-to-speech engine that merges the 3D data to deliver precise, directional voice routing.   🏥 Clinical & Practical ImpactBy replacing tactile guesswork with predictive spatial mapping, OmniSense empowers the visually impaired with 3D spatial intelligence, restoring independence safely. The system is designed to minimize fall risks in complex indoor environments. Current prototype results demonstrate a 95% collision avoidance rate, establishing a foundation for future integration directly into lightweight smart glasses.
